## Tag.app on Windows

Recorded after the release, on 2026-11-04, to support Tag.app for Windows from
v0.4.0. The checks follow
[Qualifying Tag.app on Windows](../testing/windows-tag-app-qualification.md).
The live checks ran on Windows 11 ARM64 in a UTM VM on Apple silicon, using
v0.4.0 alpha builds while their fixes were developed. None ran on the v0.4.0
build itself or on an x64 machine.

- Install Tag: **PASS**: Tag.app's **Install Tag** finished on a clean
  install with `v0.4.0-alpha.38` and `alpha.39`, after
  [#282](https://github.com/klovr-co/hover-tag/pull/282),
  [#283](https://github.com/klovr-co/hover-tag/pull/283),
  [#286](https://github.com/klovr-co/hover-tag/pull/286) and
  [#287](https://github.com/klovr-co/hover-tag/pull/287).
- Add a Tag: **PASS**: in the real Tag.app with `alpha.39`
  ([#294](https://github.com/klovr-co/hover-tag/pull/294)), and with
  `alpha.42`, where the `hover-tag-lab` organization's workspace
  `T0C83FHGC20` was picked by itself
  ([#301](https://github.com/klovr-co/hover-tag/pull/301)).
- Tag starts: **PASS**: with `alpha.42` and the
  [#303](https://github.com/klovr-co/hover-tag/pull/303) fix applied,
  `tag start` reported the Tag connected and sent its welcome DM. Home showed
  1 of 1 online.
- Stop and start: **PASS**: stopping and starting from Tag.app brought the Tag
  back online in about 55 s ([#303](https://github.com/klovr-co/hover-tag/pull/303)).
- Install, update and uninstall keep the runtime: **PASS** in CI: the
  `windows-latest / Tag.app` job installs the NSIS build, reinstalls it with
  `/UPDATE` and uninstalls it, and the runtime in `%LOCALAPPDATA%\Tag` stays
  unchanged ([#306](https://github.com/klovr-co/hover-tag/pull/306)).
- Not run on Windows: a thread reply to a Slack mention, an answer from
  memory, no console windows after
  [#297](https://github.com/klovr-co/hover-tag/pull/297), the tray, **Keep
  Tags running** after signing out, `tag upgrade`, Tag.app updating itself, the
  SmartScreen warning, and uninstalling from **Settings**.

### Decision

**GO** from the owner to support Tag.app for Windows on the checks above. The
