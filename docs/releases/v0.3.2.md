# What's New in 0.3.2

A patch for Tag 0.3. Update with `tag upgrade` or from the update notice in
Tag. Nothing needs to be set up again.

This patch includes everything in 0.3.1, which was withdrawn before it reached
most installations. It also fixes the update check, so 0.3.0 installations can
update to it.

## Choose how far a Claude approval reaches

When Claude asks before an action, the private approval in Slack now opens with
one short row:

- **Allow once**
- **Always allow** the rule Claude suggests, such as
  **Always allow claude --chrome commands**
- **Deny**

**More options** shows every choice with its exact rule: **Allow for this
task**, the exact-command rule, folder access, and **Deny and stop**.

Saved rules ask for confirmation first. They apply only to that Tag and are
stored in its workspace `.claude/settings.local.json`, not in your own Claude
settings. Remove the line from that file to revoke one. Codex approvals use the
same short row.

## Fixes

- **Tags reconnect after sleep.** If a Tag's Slack connection stays down for a
  minute while the computer is awake, Tag replaces it.
- **Tags started at login find `claude` and `codex`.** They now look in the
  usual install folders.
- **Clearer startup message.** With no channels configured, Tag says channel
  mentions are off instead of listening in "(none configured)".
