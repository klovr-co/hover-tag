# Tag v0.1.1-alpha

This prerelease hardens the first public alpha without expanding its supported
deployment model.

## Security fixes

- MFS list, read, and search now share one canonical scope policy and reject
  raw, encoded, and double-encoded parent traversal.
- Managed process files include identity data so a stale PID cannot cause Tag
  to report or stop an unrelated process after PID reuse.
- The credential documentation now states explicitly that the local agent
  backend inherits bot, MFS, and ambient environment credentials.

## Reliability fixes

- `tag status` exits nonzero unless MFS is healthy and the Slack bridge is
  connected.
- `tag start` waits for Socket Mode readiness and includes the relevant log tail
  when the bridge fails during startup.
- The local secret check tolerates tracked files deleted from the worktree.

Tag remains alpha software for trusted, isolated sandbox use. Read
[SECURITY.md](../../SECURITY.md) before installation.
