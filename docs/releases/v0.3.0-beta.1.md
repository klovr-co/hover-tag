# Tag v0.3.0-beta.1

The first 0.3 beta brings Tag.app to macOS, Windows, and Linux, including the
desktop and lifecycle work merged in [#158](https://github.com/klovr-co/hover-tag/pull/158).
It also includes the AI connections and backend support from the 0.3 alpha line.

## Tag.app

- Install Tag and add a Tag through guided setup, with AI connection and Slack
  workspace configuration.
- Start, stop, and rename Tags from the app, inspect activity and logs, and
  manage AI connections and per-Tag model settings.
- Use the menu bar or system tray, open the app at login, and receive a
  notification when a Tag unexpectedly goes offline.
- Choose an update channel and update the app and runtime together under one
  product version.

## Keep Tags running

- A per-user login service starts the Tags marked to keep running and retries
  stopped bridge processes with backoff.
- The CLI and Tag.app share the same lifecycle state: starting a Tag records
  that it should keep running; stopping it clears that choice.
- Windows installation bootstraps a managed Python runtime. Existing Windows
  installations migrate dependencies on the next start.
- Slack history indexing uses the MFS server HTTP API without requiring a
  separate MFS command-line client.

## AI connections

- Use Codex or Claude as the agent backend, with shared AI connections and
  per-Tag model choices.
- Manage ChatGPT plan connections, API connections, gateway routing, and usage
  tracking from the 0.3 release line.

## Downloads and updates

Release packaging produces a universal macOS DMG, a Windows installer, Linux
Debian and AppImage packages, platform checksums, and signed app-update bundles.
The beta update feed follows the beta line; alpha builds can update forward to
this beta. Default installs continue to select stable.

## Beta limitations

- This is a prerelease. Live installation, Slack/backend operation, login
  recovery, upgrades, and app self-updates still need qualification on each
  supported platform before stable.
- Verify the macOS download is signed and notarized before distributing it to
  end users. Windows installers are currently unsigned and may show a
  SmartScreen warning.
- Tag runs with the local account's files, credentials, tools, and permissions.
  Use it with trusted users and workspaces; it is not a hardened multi-tenant
  security boundary.
